MDB & ACCDB Viewer

You're all set

Thanks for installing MDB & ACCDB Viewer. Here is how to pin it and open your first Access database.

One last step — pin it to your toolbar

1

Open the extensions menu

Click the puzzle-piece icon in the top-right corner of Chrome.

2

Pin MDB & ACCDB Viewer

Find MDB & ACCDB Viewer in the list and click the pin icon next to it, so its icon stays in your toolbar.

3

Open the side panel

Click the MDB & ACCDB Viewer icon in the toolbar. The viewer opens in the side panel, next to your current tab.

Open your first database

1

Drop a database in

Drag an .mdb or .accdb file into the panel, or click the drop area to pick one. You can open several databases at once — each gets its own tab. Password-protected files ask for the password.

2

Browse every table

Switch tables with the tabs, click a column header to sort, and type in the filter box to find rows. Long text opens in full with one click; attachments and OLE objects can be saved as files.

3

Query and export

Open the SQL console to run a query (Ctrl+Enter), then export the table or the result to CSV, Excel or JSON.

What it does

Open .mdb and .accdb

Reads databases from Access 97 through Access 2019 and Microsoft 365 — no Access installation needed.

Browse, sort and filter

Clear table view with Yes/No, dates, currency, memo fields, attachments and OLE objects.

SQL console

Run SELECT queries with joins and grouping, with autocomplete and query history.

Export to CSV, Excel, JSON

Move any table or query result into Excel, Google Sheets or your own code in one click.

Your data never leaves your computer. MDB & ACCDB Viewer reads each database locally in the browser, works offline and never changes the original file.
